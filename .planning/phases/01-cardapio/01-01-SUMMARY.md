# Entrega
Frontend Next.js 16.3.8/React/TypeScript, API Go com SQLite, catálogo, sacola, checkout e solicitação de bolo personalizados. Pedidos gravados com transação e totais calculados pelo servidor. Interface responsiva laranja/creme conforme referência aprovada. Fotos ilustrativas limpas geradas para substituir recortes do esboço.

# Verificação
`go test ./...`, `npm run build`, `npm run typecheck` aprovados. Playwright: pedido completo e orçamento aprovados; sem overflow em 375, 414, 768, 1024 e 1440 px. Screenshots inspecionadas e problema de fotos com textos do esboço corrigido.

# Limites
Catálogo e valores de demonstração. Sem pagamentos, notificações, estoque ou painel. Commits tentados, mas bloqueados por identidade Git ausente; arquivos preservados. Nenhuma configuração global de Git alterada.
